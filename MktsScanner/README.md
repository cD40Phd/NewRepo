# MktsScanner — поиск приборов МКТС на линии RS-485/RS-232

Консольная утилита (.NET 8) перебирает сетевые адреса Modbus RTU на COM-порту и показывает,
какие теплосчётчики МКТС (плата RS485E) отвечают и с какими параметрами связи.

Прибор считается найденным, если на запрос вернул корректный кадр **или ответ-исключение**
Modbus: исключение тоже означает, что адрес занят, даже если прибор не поддерживает
запрошенный регистр. Поэтому для поиска не нужна карта регистров МКТС.

## Сборка и запуск

Проект собирается в двух вариантах:

| Папка сборки | Что нужно на компьютере | Когда использовать |
|---|---|---|
| `bin\Release\net462\` | .NET Framework 4.6.2 или новее (в Windows 10/11 уже есть) | **основной вариант**, в т.ч. для Windows 7 |
| `bin\Release\net8.0\` | установленный .NET 8 Runtime, Windows 10+ | если .NET 8 уже стоит |

```bat
cd MktsScanner
dotnet build -c Release
```

На прибор/ноутбук копируйте содержимое `bin\Release\net462\` (`MktsScanner.exe` и `MktsScanner.exe.config`):

```bat
C:\MKTSCom\MktsScanner.exe --list
C:\MKTSCom\MktsScanner.exe --port COM3 --verbose
```

Ошибка `You must install .NET to run this application` означает, что запущена сборка `net8.0`
на компьютере без .NET 8 — возьмите exe из `net462`. На Windows 7 без .NET Framework 4.6.2+
установите .NET Framework 4.8 (офлайн-установщик с сайта Microsoft).

## Типовые сценарии

| Задача | Команда |
|---|---|
| Быстрый поиск на 9600 8N1, адреса 1–247 | `--port COM3` |
| Скорость прибора неизвестна | `--port COM3 --baud all --parity all` |
| Сохранить результат | `--port COM3 --csv mkts.csv` |
| Узкий диапазон адресов | `--port COM3 --from 1 --to 32` |
| Прибор не любит функцию 3 | `--function 4` или `--function 17` (Report Slave ID) |
| Преобразователь возвращает эхо | `--echo` |
| В линии помехи, ничего не найдено | `--verbose` — покажет битые кадры |

Полный список параметров: `--help`.

Коды выхода: `0` — приборы найдены, `3` — не найдены, `2` — ошибка параметров, `1` — порт не открылся.

## Время сканирования

Молчащий адрес занимает примерно `(timeout + pause) × (retries + 1)` — по умолчанию около 0,5 с.
Полный проход 247 адресов на одной скорости — около 2 минут; `--baud all --parity all`
(24 комбинации) — до 50 минут. Если скорость известна, задайте её явно, а для ускорения
уменьшите `--retries 0` и сузьте диапазон `--from/--to`. Сканирование можно прервать Ctrl+C —
найденное к этому моменту будет выведено.

## Если приборы не находятся

- Проверьте, что в меню МКТС (раздел «Плата RS485E») выставлены те же скорость и адрес.
- Поменяйте местами провода A и B.
- На крайнем приборе линии должен быть включён согласующий резистор.
