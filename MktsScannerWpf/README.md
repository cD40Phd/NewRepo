# MktsScannerWpf — оконная версия поиска приборов МКТС

WPF-приложение под .NET Framework 4.6.2 (Windows 7–11, без установки .NET 8).
Использует тот же код опроса Modbus RTU, что и консольный `MktsScanner`.

## Работа

1. Выберите порт, скорость, чётность. Для RealCOM (Moxa NPort и т.п.) оставьте включённым **DTR/RTS**.
2. **Подключить** — порт открывается один раз и держится открытым до «Отключить».
3. **Найти приборы** — перебор адресов «с/по» запросом «функция 3, регистр 0, кол-во 2»
   (как в рабочем PowerShell-скрипте). Найденные приборы попадают в таблицу, всё остальное — в журнал.
   Для сетевых COM-портов ставьте «Ожидание ответа» 1000–2000 мс.
4. Командная строка внизу (Enter — отправить, ↑/↓ — история):

| Команда | Что делает |
|---|---|
| `scan [с] [по]` | поиск приборов |
| `read 2` / `read 2 0 2` | чтение holding-регистров адреса 2 (функция 3) |
| `readin 2 0 2` | чтение input-регистров (функция 4) |
| `id 2` | Report Slave ID (функция 17) |
| `02 03 00 00 00 02` | произвольный HEX-кадр; CRC добавляется автоматически (галочка «Добавлять CRC») |
| `ports`, `clear`, `help` | список портов, очистка журнала, справка |

Журнал показывает каждый TX/RX в HEX с временем ответа и проверкой CRC.
Таблицу найденных приборов можно сохранить в CSV.

Сборка: откройте `NewRepo.sln`, стартовый проект `MktsScannerWpf`, файл `bin\Release\net462\MktsScannerWpf.exe`.
