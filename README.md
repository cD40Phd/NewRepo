# Мой YouTube — просмотр только разрешённых каналов

Веб-приложение для браузера телевизора (Hisense VIDAA и других Smart TV). Показывает
видео **только с каналов из белого списка**: никаких рекомендаций, поиска по всему
YouTube и перехода на чужие каналы.

Возможности:

- лента последних видео со всех разрешённых каналов и фильтр по каналу;
- поиск по названиям видео внутри разрешённых каналов;
- управление стрелками пульта, «ОК» и «Назад»; медиакнопки ⏯ ⏪ ⏩ в плеере;
- по окончании видео плеер закрывается, поэтому рекомендации YouTube не показываются;
- настройки защищены PIN-кодом;
- кэш на 30 минут, чтобы экономить квоту API.

## 1. Получите ключ YouTube Data API

1. Откройте <https://console.cloud.google.com/>, создайте проект.
2. «APIs & Services → Library» → найдите **YouTube Data API v3** → **Enable**.
3. «APIs & Services → Credentials» → **Create credentials → API key**.
4. Ограничьте ключ: *Application restrictions* → **Websites** → добавьте адрес, где
   будет размещено приложение (например `https://<ваш-логин>.github.io/*`);
   *API restrictions* → только **YouTube Data API v3**.

Бесплатной квоты (10 000 единиц в сутки) хватает с большим запасом: одно обновление
стоит ≈2 единицы на канал.

## 2. Укажите каналы

Откройте `config.js` и заполните:

```js
apiKey: 'AIza...',
channels: [
  '@SomeChannel',                          // handle
  'UCxxxxxxxxxxxxxxxxxxxxxx',              // ID канала
  'https://www.youtube.com/@AnotherOne',   // или ссылка
],
pin: '1234',
```

Те же параметры можно поменять прямо на телевизоре через кнопку ⚙. Они сохранятся
в браузере телевизора и будут важнее значений из `config.js`.

## 3. Разместите приложение

Проще всего через GitHub Pages: **Settings → Pages → Deploy from a branch** → ветка
и папка `/ (root)`. Через минуту приложение будет доступно по адресу
`https://<ваш-логин>.github.io/<репозиторий>/`.
(Для приватного репозитория Pages требует платный тариф GitHub.)

Подойдёт любой статический хостинг или локальный сервер в домашней сети,
например `python3 -m http.server 8080`. Открывать `index.html` как файл нельзя:
плеер YouTube не работает с `file://`.

## 4. Установите на телевизор как приложение

В VIDAA есть скрытый установщик веб-приложений. Он добавляет значок на главный
экран рядом с другими приложениями.

1. На пульте «Домой» → «Приложения» → **Браузер**.
2. В адресной строке введите `hisense://debug` и нажмите «ОК».
3. Заполните поля:
   - **Name**: `Мой YouTube`
   - **URL**: `https://cd40phd.github.io/NewRepo/`
   - **Icon**: `https://cd40phd.github.io/NewRepo/icon.png`
   - **Resolution** (если есть): `1080`
4. Нажмите **Install**. Приложение появится в «Приложениях» в конце списка.
   Его можно переместить на главный экран, как любое другое.

Способ неофициальный и зависит от прошивки. Если страница `hisense://debug`
не открывается, просто добавьте адрес приложения в закладки браузера.
Публиковать свои приложения в VIDAA Store могут только партнёры Hisense.

## Ограничения

- Некоторые авторы запрещают встраивать свои видео. Такие видео не воспроизведутся,
  приложение покажет сообщение.
- Внутри встроенного плеера YouTube остаётся кнопка-логотип. На телевизоре фокус
  туда не попадает, но мышью или на телефоне по ней можно уйти на youtube.com.
- В России YouTube работает с замедлением. Если видео не загружаются, проблема
  в сети, а не в приложении.
- Браузер телевизора остаётся браузером, поэтому строгим «родительским контролем»
  приложение не является.
